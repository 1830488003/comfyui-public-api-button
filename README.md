# 默默画图 🎨

SillyTavern 傻瓜式生图插件。装上、填卡密，聊天时自动出图。

- **不用装世界书**（插件内置绘图指令，装上即生效）
- **不用手点按钮**（回复后自动识别场景出图）
- 43 种画风，还能自己定义
- 5 种尺寸（含 720p 高清）
- 新用户免费领 50 次

## 安装

1. 打开 SillyTavern，点右上角 🎲 扩展图标
2. 选「Download Extension / Update」
3. 粘贴：`https://github.com/1830488003/comfyui-public-api-button.git`
4. 点 Download，装完重载酒馆页面
5. 插件设置里点「获取免费额度」领 50 次
